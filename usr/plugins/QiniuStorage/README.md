# QiniuStorage

适用于 Typecho 1.3 的七牛云 Kodo 附件存储插件，不依赖第三方 PHP SDK。

## 使用方法

1. 在七牛云创建**公开** Kodo 空间。正式使用建议绑定支持 HTTPS 的自定义访问域名。
2. 在 Typecho 后台启用“七牛云 Kodo 附件存储”。
3. 进入插件设置，填写空间名称、AccessKey、SecretKey、访问域名和存储区域。
4. 上传一个测试图片，确认后台返回的地址使用配置的七牛云域名。
5. 再测试替换和删除附件。

新上传附件会保存在七牛云。启用插件前的本地附件仍可访问；替换旧附件时，新文件会迁移到七牛云。

插件当前面向公开空间。私有空间的临时下载 URL 会过期，不适合直接写入文章内容。

当前使用七牛表单直传，单个附件需小于 1 GB。覆盖同名附件后，如果仍看到旧内容，请在七牛 CDN 控制台刷新对应 URL 的缓存。

七牛提供的 `*.clouddn.com` 测试域名通常不支持 HTTPS，插件会自动使用 HTTP。站点正式启用 HTTPS 前，请换成已配置证书的自定义 CDN 域名，避免混合内容。
