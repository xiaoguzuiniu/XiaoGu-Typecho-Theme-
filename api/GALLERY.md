# iOS 分享照片到相册

## 准备工作

1. 在 Typecho 后台进入“控制台 → 外观 → 设置外观 → 相册设置”。
2. 配置相册分类。
3. 点击“生成安全密钥”，保存设置后复制密钥。
4. 接口地址为 `https://你的域名/api/gallery`。

## 快捷指令流程

新建快捷指令“上传到我的相册”，在详情中开启“在共享表单中显示”，接收类型只保留“图像”。

依次添加以下动作：

1. 如果“快捷指令输入”没有任何值，使用“选择照片”，并开启“选择多张”。
2. “获取 URL 内容”：
   - URL：`https://你的域名/api/gallery`
   - 方法：GET
   - 请求头：`Authorization` = `Bearer 你的密钥`
3. 从返回的字典依次取得 `data`、`albums`，使用“从列表中选取”选择上传分类。
4. “对快捷指令输入中的每一项重复”：
   - 使用“转换图像”转为 JPEG，建议将长边调整到 2560 像素以内。
   - 使用“Base64 编码”。
   - 将编码结果“添加到变量”，变量命名为 `照片编码列表`。
5. 使用“合并文本”合并 `照片编码列表`，自定分隔符为 `|XIAOGU_IMAGE|`。
6. 再添加一次“获取 URL 内容”：
   - URL：`https://你的域名/api/gallery`
   - 方法：POST
   - 请求头：`Authorization` = `Bearer 你的密钥`
   - 请求正文：JSON
   - `album`：第 3 步选择的分类
   - `images_base64`：第 5 步合并后的文本
7. 从响应中取得 `message` 并使用“显示结果”。

完成后，在 iPhone 相册中多选照片，点击“分享”，选择“上传到我的相册”，再选择分类即可。

## 接口说明

- `GET /api/gallery`：返回后台配置的分类列表。
- `POST /api/gallery`：上传照片并追加到 `gallery` 页面。
- 一次最多上传 20 张，每张不超过 12MB。
- 仅接受后台已配置的分类。
- 所有请求都必须携带 `Authorization: Bearer 密钥`。
